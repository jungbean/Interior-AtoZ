# 갈 것인가 수라의 길로

인테리어를 처음 맡기는 사람을 위한 진행판입니다.
2026년 봄에 24평 아파트 전체 공사를 직접 진행하며 남긴 기록을 정리했습니다.

**https://jungbean.github.io/Interior-AtoZ/**

## 담긴 것

- **일정** — 입주 희망일을 넣으면 언제까지 무엇을 해야 하는지 거꾸로 계산합니다. 계약 후에는 착공일 기준으로 오늘의 공정을 짚어 줍니다.
- **요청서** — 채우면 모든 업체에 똑같이 보낼 견적 요청서가 만들어집니다. 조건이 같아야 견적을 비교할 수 있습니다.
- **업체** — 후보를 모아 두고 여덟 가지 기준으로 거릅니다.
- **견적과 계약** — 예산을 판단하는 기준, 집계표에서 빠진 공정, 나중에 붙는 항목, 계약서 필수 조항을 대조합니다.
- **공정** — 22일이 어떻게 흘러가고 그날 집주인이 무엇을 챙겨야 하는지.
- **하자 점검** — 인수인계 날 집을 돌며 공간별로 기록하고, 업체에 보낼 목록을 만듭니다.
- **용어** — 견적서와 상담에서 설명 없이 나오는 말 64개.

## 참고

- 금액은 조건에 따라 크게 달라져서 적지 않았습니다. 대신 견적을 판단하는 방법을 담았습니다.
- 한 번의 공사 경험에서 나온 것이라 조건이 다르면 달라질 수 있습니다.
- 입력한 내용은 브라우저에만 저장되며 서버로 전송되지 않습니다.
- 단지 관리규약과 공사 범위에 따라 달라지는 부분은 관리사무소와 업체에 직접 확인하세요.

## 만든 방법

정적 HTML 한 장입니다. 빌드 도구나 프레임워크를 쓰지 않았고, 외부 요청은 웹폰트뿐입니다.
